# Pracownik służby: kolejka w Mobile

Po zalogowaniu kontem pracownika Mobile otwiera Panel Służby. Wymagane jest aktywne
przypisanie do konkretnej służby; jeśli go brakuje, aplikacja pokazuje komunikat i
umożliwia wylogowanie. Uprawnienia nadaje administrator w
[panelu WEB](using-web-admin.md). W Mobile 1.0 nie ma mobilnego panelu administratora.

## Praca z kolejką

Na górze ekranu widzisz nazwę przypisanej służby. Filtry „Wszystkie”, „Zgłoszone”,
„W trakcie” i „Naprawione” zawężają listę; liczniki pomagają ocenić obciążenie.
Otwórz kartę, aby zobaczyć opis, adres, dane zgłaszającego i prywatne zdjęcie.
Lista dotyczy wyłącznie Twojej służby, nie całego miasta.

W szczegółach możesz ustawić status, oznaczyć zgłoszenie jako sprawdzone oraz dodać
zdjęcie po naprawie. Po każdej zmianie poczekaj na potwierdzenie zapisu. Jeżeli
sprawa zmieniła się równolegle, odśwież jej szczegóły i ponownie oceń stan — klient
nie nadpisuje po cichu nowszej wersji.

Gdy aplikacja wykryje brak sieci, działania zapisujące są zablokowane. Wcześniej
pobrane dane mogą pozostać widoczne z cache, lecz nie są dowodem aktualnego stanu.
Po odzyskaniu połączenia odśwież kolejkę przed zmianą statusu.

Przypisywanie spraw między służbami i zarządzanie kontami należy do administratora WEB.
Wariant pracy z przeglądarki opisuje [przewodnik służby WEB](using-web-service.md).
